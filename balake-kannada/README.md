# baLake kannaDa

A small, self-contained practice site for everyday spoken Kannada (baLake kannaDa),
written in English letters only. Content follows the course exercise sheets
(Lessons 1–10), grouped into 7 units.

- Open `index.html` in any browser. No build step, no dependencies.
- Spelling: doubled vowel = long vowel (`aa`, `ii`, `uu`, `ee`, `oo`);
  a capital letter = the hard, stressed sound (`T D N L Sh`), never the first letter by default.
- Daily streak, XP goal and unit progress are saved in the browser's localStorage.
- Optional streak reminders (up to 3 a day, only while the daily goal is not met) fire while the page is open, as desktop notifications if the browser allows them, otherwise as an in-page banner and flashing tab title.
